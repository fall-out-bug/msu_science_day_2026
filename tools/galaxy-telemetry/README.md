# Журнал действий «Первой смены»

Сайт отправляет разрешённые события на `POST /telemetry/v1/events`.
Коллектор хранит их в отдельной SQLite 30 дней; удаление выполняется при
старте, при приёме и каждый час. Публичного чтения или экспорта нет.
Локальный nginx ограничивает размер/частоту и отключает журналирование
маршрута. Журналы внешнего HTTPS-прокси проверяются отдельно перед включением.

ZIP работает без HTTP: журнал доступен в «О проекте → Для стендиста: журнал
смены». Перезагрузка сохраняет смену в пределах вкладки; закрытие вкладки
может удалить журнал. Перед закрытием его можно сохранить в JSON. При
отказе sessionStorage игра продолжает работать с журналом в памяти и
сообщает об ограничении. Пределы и повторная отправка описаны в
[техническом плане](../../docs/design-2026-10-08/technical-plan.md#телеметрия).

## Локальная выгрузка владельца

Каталог `~/.local/share/science-day/galaxy-telemetry/` вне Git создаёт
`tools/galaxy-release/deploy.sh`; другой путь задаётся переменной
`GALAXY_TELEMETRY_DATA_DIR`.
Процесс контейнера работает как UID 1000. Команды из корня репозитория:

```bash
python3 tools/galaxy-telemetry/admin_export.py ~/.local/share/science-day/galaxy-telemetry/telemetry.sqlite3
python3 tools/galaxy-telemetry/admin_export.py ~/.local/share/science-day/galaxy-telemetry/telemetry.sqlite3 --json > /protected/galaxy-events.json
```

Первая команда открывает БД только для чтения и выводит сводку: версии,
достигнутые этапы, завершение, помощь, известные ошибки и длительности.
Медиана вычисляется обычным способом; p90 — ближайший ранг. Длительность
смены ограничена последним полученным событием, этапа — следующим входом
на этап. Эти интервалы не измеряют время активного внимания. Отсутствие
финала не устанавливает причину остановки. Сводка не содержит ID смен.

`--json` добавляет записи с временными случайными ID смен и разрешёнными
полями событий. Выгрузка остаётся у владельца; её срок хранения также
ограничен 30 днями. Время внешнего HTTPS-прокси и локальной БД — разные
границы проверки. Подробности публикации — в
[порядке выпуска](../galaxy-release/RELEASE.md).

## Проверки

```bash
bun tools/galaxy-telemetry/check-client.mjs
python3 tools/galaxy-telemetry/test_server.py
python3 tools/galaxy-telemetry/test_admin_export.py
/home/zhuckoff/projects/msu/science_day/.venv/bin/python tools/galaxy-telemetry/check-integration.py
```

Интеграционный тест использует временные HTTP/SQLite и реальный браузер.
Это проверка локального приёма, а не доказательство готовности публичного
маршрута. В тестовом прокси Origin удаляется; производственный Origin
проверяется отдельно на публичном HTTPS.
