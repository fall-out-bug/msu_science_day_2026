# Публикация «Первая смена»

Текущий выпуск: `2026.10.07-observatory.2`, образ
`sd2026-public:galaxy-20261007-2`. Главная страница — ночная обсерватория
с обязательным поиском трёх галактик на карте.

Этот каталог содержит команды переключения корня `https://sd2026.beetles.family/` на
готовую сборку из `designlab/galaxy-shift/releases/web/`. Он не меняет
`compose.public.yaml`, действующий Dockerfile или сервис комментариев.

## Зафиксированное исходное состояние

На 6 октября 2026 года основной контейнер — `sd2026-web-1` с образом
`sd2026-public:scenario-comments` (`sha256:8233f9ba006d…`), который слушает
`192.168.50.12:8080`. Отдельный `sd2026-comments-1` хранит SQLite в
`var/scenario-comments`; он не пересоздаётся командами выпуска. DNS домена
разрешается в `77.37.212.181`; это внешний HTTPS-прокси. Из данного хоста
HTTPS отвечал нестабильно: одна из трёх проверок дала HTTP 200, две завершились
тайм-аутом. Поэтому внешняя доступность должна быть подтверждена после
переключения отдельной проверкой.

Новый образ наследует именно этот работающий образ, переносит прежний сайт в
`/legacy/`, возвращает `docs/` на прежний путь и сохраняет nginx-маршрут
`/scenario-comments`. Старый автономный архив также доступен как
`/legacy/night-shift.zip`; новый — `/galaxy-shift.zip`.

## Контролируемое переключение

После готовности и локальной проверки игры собрать образ с уникальным тегом:

```bash
tools/galaxy-release/build-image.sh sd2026-public:galaxy-20261007-1
tools/galaxy-release/deploy.sh sd2026-public:galaxy-20261007-1
```

`deploy.sh` пересоздаёт только `sd2026-web-1`, затем подтверждает: образ
контейнера, новую главную страницу, `/legacy/`, документацию, новый ZIP и
работу контейнера комментариев. Для проверки снаружи выполнить с независимой
сети запросы к `/`, `/legacy/`, `/docs/first-shift-scenario.html` и
`/scenario-comments`. Локальная проверка не доказывает внешний HTTPS-путь.

## Откат

Если локальные или внешние проверки не проходят, вернуть прежний образ:

```bash
tools/galaxy-release/rollback.sh sd2026-public:scenario-comments
```

Этот откат также пересоздаёт только `sd2026-web-1`; данные комментариев и
образ `sd2026-public:scenario-comments` остаются нетронутыми.

Перед переключением `nginx -t` прошёл в одноразовом контейнере кандидата.
Пересоздан только `web`. Идентификатор и время запуска контейнера комментариев
сохранились. На действующем upstream подтверждены все 32 SHA-256 ресурсов,

запросов на другие домены; результат —
`designlab/galaxy-shift/evidence/published.json`.

Публичный HTTPS отдельно проверен с доступного хоста `superduper`: все
32 ресурса и новый ZIP совпали со сборкой, прежняя игра и архив открылись.

прошёл весь маршрут игры на публичном адресе без ошибок JavaScript и
сторонних запросов. Проверка TLS оставалась включённой. Туннель закрыт после
проверки; службы и VPN не менялись. Отчёты — `evidence/public-https.json` и
`evidence/public-browser.json` в каталоге игры.

прошли, другие завершились тайм-аутом или отказом соединения. Проверка через
другой хост подтверждает опубликованную версию и полный публичный маршрут,
но не устанавливает причину сбоев прямого пути или доступность из любой сети.

Повторная проверка (проверяет файлы, игровой маршрут и отсутствие сторонних
