## Подготовка и проверка

Рабочий каталог выпуска — корень `science_day-cnn`. Сначала выполнить
[приёмку игры](../../designlab/galaxy-shift/README.md) и
[матрицу A/V](../../docs/design-2026-10-08/acceptance.md). Сборка требует все
22 архитектуры и проверяет происхождение таблиц. После распаковки ZIP пройти
игру без сети; сохранить доказательства в репозитории или архиве поставки.
Затем собрать страницы дизайна, сохранив исторические привязки комментариев:

```bash
python3 designlab/galaxy-shift/build-galaxy.py
python3 tools/scenario-review/build-current-design.py
```

Перед включением телеметрии проверить журналирование её маршрута на внешнем
HTTPS-прокси. В локальном nginx приём ограничен POST, размером и частотой;
access/error logging маршрута отключены. Контейнер телеметрии имеет отдельную
SQLite, срок хранения 30 дней и локальную административную выгрузку.

Проверено 9 октября: SSH-псевдоним `synology` ведёт на внешний прокси
`sd2026.beetles.family:443 → 192.168.50.12:8080`. Его `access_log` отключён;
общий сетевой `error_log` уровня `error` в syslog сохранён. Он не является
журналом действий игры и может содержать сведения запроса при сетевой ошибке.
Снимок настроек — `docs/design-2026-10-08/evidence/proxy-audit.json`.

Зафиксировать исходники коммитом, затем собрать образы с уникальными тегами:

```bash
docker build --builder default --pull=false -t sd2026-telemetry:complete-20261008-1 tools/galaxy-telemetry
tools/galaxy-release/build-image.sh sd2026-public:galaxy-20261009-night-3
```

Базовый образ `sd2026-public:scenario-comments` закреплён точным SHA-256 в
`build-image.sh`. Из него сохраняются `/legacy/`, `night-shift.zip` и
исторические документы. Новые страницы дизайна копируются из опубликованного
набора. Перед переключением проверить `nginx -t` в одноразовом контейнере.

## Переключение и приёмка

```bash
tools/galaxy-release/deploy.sh sd2026-public:galaxy-20261009-night-3
```

Команда создаёт отдельный каталог БД телеметрии, запускает её контейнер и
дожидается healthcheck, затем пересоздаёт только web. Идентификатор и время
старта `sd2026-comments-1` должны остаться прежними; его SQLite не изменяется.
По умолчанию БД находится в `~/.local/share/science-day/galaxy-telemetry/`,
вне рабочего дерева Git; путь можно задать через `GALAXY_TELEMETRY_DATA_DIR`.
Удаление рабочей ветки поэтому не удаляет журнал. Каталог закрыт режимом 0700.
Локальный upstream — `http://192.168.50.12:8080`, публичный сайт —
`https://sd2026.beetles.family/`.

`check-complete-published.py` сверяет SHA-256 всех ресурсов, ZIP и документов,
сохранность прежней игры и комментариев и выполняет видимый маршрут с
конструктором. Флаг `--preservation` принимает приватный JSON снимка хэшей,
снятого до публикации; содержание чужих комментариев в отчёт не включается.

```bash
/home/zhuckoff/projects/msu/science_day/.venv/bin/python tools/galaxy-release/check-complete-published.py --base http://192.168.50.12:8080 --preservation /tmp/science-day-night-preservation.json --evidence docs/design-2026-10-09/evidence/published-upstream.json
/home/zhuckoff/projects/msu/science_day/.venv/bin/python tools/galaxy-release/check-complete-published.py --base https://sd2026.beetles.family --ssh-host superduper --preservation /tmp/science-day-night-preservation.json --evidence docs/design-2026-10-09/evidence/published-https.json
```

HTTPS проверяется с обычной проверкой сертификата через временный SSH SOCKS
к доступному внешнему хосту; туннель закрывается после проверки. Это не меняет
VPN или службы хоста. Локальный PASS не считается публичным PASS. Для
телеметрии дополнительно сверяются события проверочной смены в SQLite,
публичный запрет чтения и сохранение данных после перезапуска её контейнера.

разрешения владельца.
