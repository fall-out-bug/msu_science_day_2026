# Комментарии к сценарию

Страница в репозитории: [`first-shift-scenario.html`](../../designlab/comparison/docs/first-shift-scenario.html).

Кнопка «＋» у абзаца, реплики или строки таблицы открывает обсуждение этого фрагмента. Комментарии общие, без имени и регистрации, с датой и временем. При открытии обсуждения список обновляется. Доступна выгрузка всех комментариев в JSON. Отправка комментария не меняет Markdown сценария.

## Хранение и привязка

Сервис Python stdlib хранит записи в SQLite: `var/scenario-comments/comments.sqlite3`. Каталог исключён из Git, смонтирован в контейнер `sd2026-comments-1` и переживает пересоздание контейнеров. Резервировать через SQLite backup API, а не копировать файл во время записи. Комментарии видны всем читателям ссылки; удаления через публичный интерфейс нет. Текст выводится как текст, не HTML. API ограничивает поля, объём запроса и допустимые фрагменты; nginx ограничивает частоту обращений.

`blocks.json` фиксирует 196 фрагментов документа `first-shift-v1` после уточнения от 6 октября. Все 180 прежних идентификаторов сохранены; новые имеют префикс `r2p`. Идентификаторы явно записаны в HTML как `data-review-id`. При правке структуры документа нужно сохранять эти идентификаторы либо выпустить новую версию и отдельный набор привязок; нельзя молча переназначать старые комментарии другому тексту. Каноническая цитата записывается сервером, а не принимается от посетителя.

JS/CSS лежат рядом с HTML в `designlab/comparison/docs/`. При открытии через `file://` используется только локальное хранилище браузера; интерфейс явно сообщает об этом. Локальные заметки автоматически на сервер не отправляются. Повторный HTML-экспорт должен сохранять подключение JS/CSS.

## Проверка

Из корня проекта:

```bash
.venv/bin/python tools/scenario-review/check.py
```

Тест использует временную SQLite и проверяет отправку без имени, видимость в независимом браузере, привязку к фрагменту, безопасный вывод HTML-подобного текста, мобильную ширину, отклонение неверной привязки и чужого Origin, сохранность после перезапуска. Browser plugin недоступен; используется установленный Playwright.

## Публикация

Веб-образ расширяет сохранённый действующий образ игры `sd2026-comparison:before-comments-20261006`, а не пересобирает игру из изменённых локальных исходников. Для новой версии игры сначала явно сменить базовый образ. Используется локальный Docker builder: другой настроенный builder не видит локальный базовый образ.

```bash
docker build --builder default --pull=false -t sd2026-comments:local tools/scenario-review
docker build --builder default --pull=false -t sd2026-public:scenario-comments -f tools/scenario-review/Dockerfile.web .
docker compose -f compose.public.yaml up -d --no-build --pull never
```

`compose.public.yaml` задаёт UID/GID владельца локального каталога данных. При переносе на другой хост их нужно согласовать с правами этого каталога. API не публикует отдельный порт: nginx основного сайта проксирует `/scenario-comments`. Сервис сравнения на 8081 не меняется. Конфигурация nginx с API лежит в этой папке отдельно от конфигурации игры.

6 октября 2026: целевой тест прошёл. На опубликованном HTTP upstream проверены отправка, чтение из независимого браузера и чтение после перезагрузки. Единственная созданная проверочная запись удалена по её уникальному тексту; пользовательские записи не затронуты.

Обновление по замечанию о классификации: `first-shift-changes.html` показывает diff; `.diff` доступен для скачивания. Изменённые фрагменты основной страницы выделены зелёным. Если цитата сохранённого комментария отличается от текущего текста, обсуждение показывает раскрываемую прежнюю редакцию. Исходный снимок до правки сохранён в `docs/redesign-2026-10-05/first-shift-before-classification.md`.

Уточнение отображения: diff встроен непосредственно перед изменёнными фрагментами основного HTML (красное «Было», зелёное «Стало»). Кнопка в начале скрывает/раскрывает прежние формулировки. `first-shift-changes.html` перенаправляет на основной документ. Блоки прежнего текста исключены из привязки комментариев.


## Редакция «Галактики» · 6 октября 2026

Текущий документ переписан под многоклассовую классификацию изображений галактик и живого стендиста. 168 новых фрагментов имеют идентификаторы `g3p…`; все 196 прежних фрагментов и их идентификаторы сохранены в раскрываемых блоках перед соответствующими разделами. Комментарии к разным редакциям не смешиваются. Сервис использует тот же документ `first-shift-v1` и общую таблицу допустимых привязок (364 записи).

Текущий Markdown: `docs/redesign-2026-10-05/first-shift-scenario.md`. Предыдущий: `first-shift-before-galaxies.md`; текстовый diff: `first-shift-galaxies.diff`. На странице показываются обе редакции; публикация не меняет код игры.

Проверены три новые SVG-схемы, 364 привязки, переключение прежнего текста, раздельные комментарии к текущей и предыдущей редакциям и размеры 1280/390 px. Тест `check.py` работает с текущими `g3p`-фрагментами и временной SQLite.

## Дизайн-документ «Атлас галактик» · 6 октября 2026

Единый HTML: `/docs/galaxy-game-design.html`; исходники и сборка описаны в `docs/design-2026-10-06/README.md`. В документ включены концепты обсерватории и помощника, три работающих демонстратора механик, научные изображения с атрибуцией, педагогическая и техническая части. `/docs/galaxy-design-offline.zip` содержит автономную копию с иллюстрациями и сценарий.

Комментарии документа используют `galaxy-gdd-v1` и 333 привязки из `gdd-blocks.json`. Прежний сценарий остаётся `first-shift-v1`; обе страницы используют общую SQLite, но отдельные обсуждения. Миграция данных не нужна.

`check-design.py` прошёл: все изображения, две встроенные схемы, четыре ширины экрана, карта рабочих мест, три механики, видимость комментария в независимом браузере, изоляция документов и извлечённый ZIP без внешних запросов. Тест использовал временную базу.

## Актуальная редакция «Ника и модель» · 6 октября 2026

`build-design.py` теперь собирает оба текущих документа из исходников, а `build-navigation.py` — восемь макетов `assets/navigation-nika/`. Прежние HTML сохранены как `galaxy-game-design-before-nika.html` и `first-shift-scenario-before-nika.html`. Старые цитаты и идентификаторы остаются в реестрах; новые префиксы `n4d` и `n4s` не переиспользуют привязки. Схема SQLite и идентификаторы документов API не меняются.

Актуальные решения: Ника и модель на рабочем экране, архивные снимки с оговоркой про Roman, утка отложена, основной цикл исправления данных, дополнительная пара CNN на отдельно указанном подготовленном наборе. Подробности и действующие команды: `docs/design-2026-10-06/README.md`. Предыдущие разделы этого файла описывают историю поставок.
