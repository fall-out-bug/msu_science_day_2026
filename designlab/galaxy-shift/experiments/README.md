# Воспроизведение опыта CNN

Игра использует заранее рассчитанные результаты обучения свёрточной нейронной
сети (CNN). Таблица содержит все 2187 сочетаний подписей семи изменяемых
изображений для каждого из двух вариантов архитектуры: 4374 обучения. Остальные
два учебных изображения имеют фиксированные подписи. Архив за пределами основной четвёрки
не добавляет изображения в этот опыт.

## Условия и результаты

`cnn-label-correction/protocol.json` фиксирует условия пилота.
`run_pilot.py` использует существующую NumPy-реализацию из `cnn-prepare.py`:
обучаются веса свёрточных слоёв и линейного классификатора, а не только
классификатор. Перед расчётом
проверяются SHA-256 исходных JPEG. Девять учебных изображений отделены
от трёх изображений знакомой проверки и трёх итоговых изображений.

У одно- и двухблочной сети совпадает инициализация общих параметров;
дополнительный блок получает фиксированную инициализацию. Для каждого
варианта обучение начинается заново с новым состоянием оптимизатора.
Параметры: seed 20261006; центральный квадрат со стороной 75% от меньшей
стороны исходного кадра; изображение в оттенках серого 32×32 пикселя;
420 полнопакетных шагов Adam с learning rate 0.025; без аугментаций.
Архитектура — один или два повтора «свёртка 3×3 + ReLU», затем глобальное
усреднение карт признаков, линейный классификатор и softmax.

Пилот проверяет исходное и исправленное состояния с четырьмя новыми и тремя
старыми подписями. Его конкретные значения относятся только к этому маленькому
набору; они не служат основанием выбирать архитектуру или обещать ребёнку
улучшение.

Итоговые изображения уже рассматривались авторами в предыдущей версии.
Они не участвовали в обучении, но не являются новым независимым научным
тестом. Один seed и три проверочных примера не оценивают надёжность модели.
Значения softmax — нормированные оценки модели для трёх категорий; без
калибровки они не являются вероятностями правильности.

## Проверки

Из корня репозитория, Python с NumPy и Pillow:

```bash
python3 designlab/galaxy-shift/experiments/audit_cnn_pilot.py
python3 designlab/galaxy-shift/experiments/cnn-label-correction/generate_cnn_experiments.py --check
python3 designlab/galaxy-shift/experiments/audit_cnn_table.py
```

`--check` сверяет научный JSON с поставляемым JavaScript, происхождение
данных, полноту таблицы и повторяет обучение для пяти сочетаний подписей
на обеих архитектурах. Независимый аудит проверяет границы выборок,
соответствие подписей и результатов, изменение обучаемых весов и воспроизводимость.
Это не повторное обучение всех 4374 вариантов.

## Пересчёт

Следующие команды перезаписывают артефакты, поэтому нужны только при
намеренном изменении эксперимента:

```bash
python3 designlab/galaxy-shift/experiments/cnn-label-correction/run_pilot.py
python3 designlab/galaxy-shift/experiments/cnn-label-correction/generate_cnn_experiments.py --workers 4
```

Полная генерация сохраняет `cnn-label-correction/cnn-experiments.json`
и `../cnn-experiments.js`; браузер читает только JavaScript. В источнике
записаны хэши протокола и расчётного кода. При изменении научных условий
нужен полный пересчёт, а не обновление метаданных старой таблицы.
Полная генерация запускает независимые CPU-процессы с одним BLAS-потоком
на процесс; число процессов задаётся явным `--workers`. В метаданных таблицы
сохранены суммарное время отдельных обучений и среднее время одного обучения.
Это не время обучения в браузере и не обещание скорости на другом оборудовании.

Пилот описан в `cnn-label-correction/PILOT-RESULTS.md`, независимый аудит —
в `CNN-PILOT-AUDIT.md`. Исторические опыты 1-NN и отдельное сравнение CNN
сохранены в родительской директории, но новый игровой маршрут их не использует.
