# Первая смена — ИИ в астрономии

Автономная игра для Science Day: разметить снимки галактик, проверить ответы учебной модели, исследовать ошибку в старых метках, сравнить результаты и по желанию открыть опыт со свёрточными нейронными сетями.

## Как играть

Откройте `index.html` в браузере или распакуйте `releases/galaxy-shift.zip` целиком. Сервер и интернет не нужны. В обсерватории можно открыть карту неба, подойти к столу или узнать о трёх реальных применениях ИИ. Перед разметкой найдите каждую из трёх галактик на карте: перетащите её в прицел или нажмите на метку объекта. После наведения откроется архивный снимок Hubble. Колесо мыши и кнопки +/− меняют масштаб, стрелки перемещают карту. Перетащите снимок к метке либо нажмите её. Клавиши 1, 2 и 3 тоже выбирают метку. Снимки можно увеличивать; помощь Ники объясняет видимый признак.

Состояние сохраняется при переходах внутри вкладки. «Обсерватория» возвращает в комнату, «Продолжить» — к текущему шагу. Перезагрузка начинает новую смену. Звук включается добровольно. Есть режим уменьшенной анимации. Аккаунты и отправка данных не требуются.

## Данные и научная рамка

15 неизменённых снимков NASA/ESA Hubble: девять учебных, три для повторной проверки, три для финала. Это архивные изображения, не снимки Roman. Ночная обсерватория с Никой и освещением — единая художественная сцена; её звёзды за окном не являются картой наблюдений. Отдельная интерактивная карта использует атлас NASA SVS и 2058 звёзд HYG v4.1, совместно спроецированных с координатами галактик. Источники — `sky-provenance.json`. Снимки открываются из архива; игра не изображает получение фотографий Hubble наземным телескопом.

Основная модель — метод ближайшего соседа по автоматически вычисленным признакам распределения яркости. Для пяти редактируемых меток подготовлены все 243 комбинации. Ответ соответствует метке ближайшего учебного примера. Изменение метки делает текущий результат устаревшим и сохраняет первую проверку для сравнения. Повтор без изменений показывает тот же опыт.

При справочных метках ребёнка исправление старых меток меняет повторную проверку с 1/3 на 2/3. Известная авторам итоговая подборка даёт 1/3: это слабый учебный метод, который ещё ошибается. Показатели не подменяются обещанием улучшения. Эта малая авторская подборка не доказывает качество научного классификатора.

Дополнительный опыт сравнивает два заранее обученных CNN с одним и двумя свёрточными блоками. Оба дают 2/3 на знакомых проверочных снимках. Используется отдельный фиксированный набор с корректными метками; его результаты не выдаются за обучение на текущих метках ребёнка. Два блока не обещают преимущество.

Источники, атрибуция и зафиксированные контрольные суммы — `provenance.json`. Метод и подготовка — `DATA-NOTES.md`. Иллюстрации, промпты и SHA-256 — `assets/art/ART-CREDITS.md`. Точные объяснения и помощь детям — `FACILITATOR.md`. Редактура русского текста и сравнение с книгами и играми — `../../docs/design-2026-10-06/russian-copy-review.md`.

## Проверка и сборка

Из корня репозитория:

```bash
node designlab/galaxy-shift/check-model.mjs
python3 designlab/galaxy-shift/prepare-data.py --check
python3 designlab/galaxy-shift/feature-audit.py
python3 designlab/galaxy-shift/cnn-prepare.py --check
python3 designlab/galaxy-shift/check-cnn.py
python3 designlab/galaxy-shift/build-galaxy.py
python3 designlab/galaxy-shift/check-browser.py
```

В текущем окружении Python с NumPy, Pillow и Playwright — `/home/zhuckoff/projects/msu/science_day/.venv/bin/python`. В игру эти зависимости не входят. Данные подключаются локальными `script`, без `fetch` или CDN.

`sky.js` управляет наведением на карту, `astronomy.js` содержит проверенные истории Euclid, ZTF и Kepler-90i. `world.js` рисует комнату и управляет переходом к столу, `model.js` владеет состоянием, `game.js`/`galaxy.css` — инструментами и репликами. `cnn-data.js` содержит отдельный опыт. Упаковщик включает только явный набор ресурсов и научные JPEG; `build.json` фиксирует их SHA-256.

Браузерная проверка проходит основной маршрут, наведение на три галактики, открытие их снимков, перетаскивание, клавиатуру, поиск причины ответа, возвраты, помощь, CNN и сброс на 1920×1080, 1440×900, 1280×720, 390×844 и 844×390. Такой же маршрут проверяется в распакованном ZIP с заблокированной сетью. Отчёты и характерные скриншоты — `evidence/`.

Проверка графики и взрослый браузерный проход не устанавливают детское понимание или длительность. План стенда на 5–8 минут требует отдельного наблюдения с детьми. Публикация и сохранение прежней игры описаны в `../../tools/galaxy-release/RELEASE.md`.
