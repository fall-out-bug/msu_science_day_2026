# Снимок локальной работы от 9 октября 2026 года

Здесь сохранено содержимое старой рабочей папки Science Day перед её
обновлением до актуального `main`: **12 162 файла, 2 197 765 662 байта**.
В неё входили ранние прототипы, документы, астрономические данные,
иллюстрации, сборки и результаты проверок. Восстановление использует только
этот репозиторий и его историю; исходная резервная копия на Sparky не нужна.

Рабочая папка оставалась на коммите
`c450b6c8d6a774a6078638ba72fdeb20d5c62fb4`, на 71 коммит позади принятого
`main` (`44c1619d5285c7d78891ce0c5801facdf45b0057`). Часть файлов уже попала
в историю других работ, часть сохранялась только локально. Архив фиксирует
их состояние, включая незакоммиченные редакции `.gitignore`, `README.md`,
`assets/real/CREDITS.md` и `tools/generate_data.py`.

Это исторический материал. Актуальная игра, её согласованный дизайн и
подтверждённые проверки описаны в [корневом README](../../README.md).
Результаты старых проверок относятся к старым версиям.

## Что сохранено

- `app/`, `designlab/`, `tools/`, `docs/` и корневые файлы старой работы.
- `assets/`: исходные ZTF FITS, производные NPZ, данные Kepler, звёздные
  каталоги, изображения, сведения об источниках и лицензиях.
- `artifacts/`, `dist/`, `verification/`: сгенерированные данные,
  поставочные ZIP, снимки экранов и результаты проверок.
- Установленные `node_modules` и промежуточные файлы: они сохранены
  внутри сжатого архива для точного восстановления состава папки.

Действующая база комментариев `var/`, Python-окружение `.venv/`, служебный
каталог `.git/` и локальная политика агента `AGENTS.md`/`.ai/` не входили
в исходный снимок. Они остались на хосте. Архив не является резервной
копией работающего сервера и не содержит его журналов телеметрии.

## Просмотр и восстановление

Новые текстовые исходники доступны в [source/](source/), в том числе
[старый README](source/README.md),
[генератор данных](source/tools/generate_data.py),
[эксперимент с движением](source/designlab/trajectory/README.md) и
[инструментальный эксперимент](source/designlab/instrument/README.md).
`source/` содержит только уникальные текстовые файлы, а не готовый к запуску
проект. Все исходные пути перечислены в [manifest.json](manifest.json).

Нужны Git, Python 3.9+ с модулем `lzma` и полная копия репозитория.
Для shallow clone сначала выполните `git fetch --unshallow`.
Команды запускаются из корня репозитория:

```bash
# Проверить все файлы архива, включая ссылки на историю Git.
python3 tools/archive/restore.py --verify

# Восстановить старую папку в новый, ещё не существующий каталог.
python3 tools/archive/restore.py --output /tmp/science-day-2026-10-09
```

Команда восстановления проверяет части архива, содержимое каждого файла,
тип файла и права доступа. Она отказывается записывать в существующий
каталог. После успешной проверки в указанной папке будет точный состав
снимка; `.git/` в него не добавляется. Для запуска старого прототипа
используйте восстановленный `README.md`, учитывая дату его инструкций.

Временное место требуется для распаковки уникальных объектов; восстановление
дополнительно занимает около 2,2 ГБ. После завершения временные файлы удаляются.

## Как устроен архив

`manifest.json` хранит исходный относительный путь, тип, размер, права
доступа и SHA-256 каждого из 12 162 файлов. Одинаковое содержимое хранится
один раз. Для каждого пути указано одно из трёх мест хранения:

| `storage.kind` | Где находится содержимое |
| --- | --- |
| `git` | Точный Git blob, достижимый из закреплённого `historyCommit` |
| `file` | Читаемый файл по указанному пути внутри `source/` |
| `payload` | Объект с именем SHA-256 внутри сжатого архива |

`payloadParts` перечисляет части `payload/objects.tar.xz.part-*` в порядке
соединения, их размеры и SHA-256. Восстановитель соединяет их и читает
обычный tar.xz. Каждый объект внутри — обычный файл; для символьной ссылки
объект хранит текст её цели. Разбиение сохраняет небольшой размер отдельного
Git-файла; Git LFS и внешнее хранилище не используются.

Снимок содержит 6 512 уникальных объектов: 294 уже есть в истории `main`,
90 доступны в `source/`, 6 128 находятся в сжатом архиве. Ссылки на историю
используют только объекты, достижимые из коммита `44c1619`; локальные
снимки Codex и непубликуемые ветки для восстановления не нужны.

Сжатый архив занимает 917 872 916 байт (около 918 МБ) и разделён на
20 частей, каждая не больше 45 МиБ. Исходный состав папки занимает
около 2,2 ГБ; повторяющиеся файлы восстанавливаются в каждый исходный путь.

Сведения о происхождении и лицензиях сохранены вместе с материалами.
Например, историческая редакция `assets/real/CREDITS.md` совпадает с
[source/app/real/CREDITS.md](source/app/real/CREDITS.md); манифест восстанавливает
оба исходных пути. Сжатие не меняет научные данные, подписи и атрибуцию.
