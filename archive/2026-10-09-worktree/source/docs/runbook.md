# Путеводитель ведущего и оператора — «Архив неизвестного»

Офлайн-игра «Охота за звёздными аномалиями» для фестиваля «Наука 0+»
(факультет ИИ МГУ, 10–11.10.2026). Интернет, сервер, аккаунты и GPU не нужны:
игра — статические HTML/JS; снимки участков и звёздный атлас встроены
в `data.js` и `sky-data.js`.

## Новый сценарий и классический архив

По умолчанию `index.html` открывает сюжетную «Ночную смену»: выберите маршрут
**«Первая смена» — 3 дела**, **«Исследователь» — 6** или **«Астроном» — 9**.
Дежурный астроном Ника знакомит команду с рабочими местами: карта неба,
станция наблюдений и доска расследования с утренним отчётом. Иллюстрации
персонажа и обсерватории оформляют историю;
кадры исследуемых участков остаются настоящими наблюдениями ZTF из того же
`GAME_DATA`. Даты, фильтры, измерения, оценки детектора и происхождение
научных данных не заменяются иллюстрациями. Все файлы нового сценария
(`nightshift-evidence.js`, `nightshift-content.js`, `nightshift-model.js`,
`nightshift-art.js`, `nightshift.js`, `nightshift.css`) входят в оба архива;
в `phone.html` они встроены вместе с изображениями и работают без сети.

Классический сценарий доступен по адресу **`index.html?archive=1`** (для
автономной страницы — **`phone.html?archive=1`**). В нём сохранены полная
смена на 12 участков и короткая на 6; правила, жетоны, счётчики и сценарий
ведущего описаны в разделе 8. Печатный комплект из раздела 7 относится
к этому классическому набору: это прежние 12 участков, а не отдельные
сценарные материалы маршрутов на 3/6/9 дел. Инструкции установки и сведения
о происхождении данных ниже применимы к обоим режимам.

## 1. Состав поставки

После сборки появляется папка `dist/`:

| Путь | Что это |
|---|---|
| `dist/linux.zip` | архив с папкой `science-day/` (игра + `install.sh` + правовые файлы) для Linux |
| `dist/apple-silicon.zip` | тот же платформенно-независимый пакет (открывается на Mac двойным щелчком; заявки на `.app` нет) |
| `dist/phone.html` | автономная страница для телефона: все стили, скрипты, снимки, данные, звёздный атлас, истории открытий и правовые файлы (исходники атласа и тексты лицензий) встроены одним файлом |
| `dist/print/presenter.pdf` | **ключ ведущего**: сценарий, кнопки, формулы счётчиков, таблица ответов с типами, оценками, датами наблюдений и пояснениями, благодарности обзора дословно |
| `dist/print/ranking.pdf` | предварительный рейтинг алгоритма (офлайн-резерв): 12 участков по убыванию оценки, отметки прохождения порогов 1 и 3; без ответов |
| `dist/print/cards.pdf` | печатный резерв: карточки групп (кадры 1–2 с фактическими датами, пустые поля) + вырезки ведущего (кадр 3 с датой и ответ: доказательство, ограничения) |

Внутри `science-day/`: игра (`index.html`, `game.css`, `sky-map.css`, `game.js`,
`sky-map.js`, `model.js`, `data.js`, `content.js`, `sky-data.js`,
`discovery-data.js`), папка `real/` (три реальных снимка ESA/Hubble и STScI +
`CREDITS.md` с атрибуциями), `sky-source.zip` (исходные файлы покрытых
лицензиями данных звёздного атласа: каталоги созвездий, переводы, манифест,
скрипт сборки), `install.sh`, `docs/runbook.md` (этот файл), `LICENSES.txt`
(сводка происхождения + полные тексты GPL-2.0, CC BY-SA 4.0 и Free Art
License). Файлы прототипов в поставку не входят.

Точные размеры печатает сама сборка; самый большой файл — `phone.html`
(десятки МиБ: звёздная текстура 8k, снимки 12×3 и фотографии встроены).

## 2. Сборка из исходников

Зависимости подготовки (самой игре они не нужны): Python ≥ 3.12, пакеты
`numpy`, `Pillow`, `reportlab` (`tools/requirements.txt`), системный шрифт
DejaVu Sans (пакет `fonts-dejavu-core`; нужен только для PDF). Проверенные
версии: Python 3.14, numpy 2.5.3, Pillow 12.3.0, reportlab 5.0.1.

```bash
python3 -m venv .venv --system-site-packages
.venv/bin/pip install -r tools/requirements.txt
```

Полная сборка (регенерирует данные, печатный комплект и архивы):

```bash
.venv/bin/python tools/build_release.py
```

Ранняя интеграция интерфейса (без `dist/`): регенерирует `app/data.js`,
копирует `app/real/` и собирает правовые файлы `app/LICENSES.txt` (сводка +
полные тексты лицензий) и `app/sky-source.zip` (исходники данных атласа):

```bash
.venv/bin/python tools/build_release.py --data-only
```

Параметры: `--dist ПУТЬ` (папка вывода, по умолчанию `dist/`), `--app ПУТЬ`
(папка приложения, по умолчанию `app/`).

## 3. Данные: происхождение и регенерация

`app/data.js` — это `window.GAME_DATA`: `meta`, `contact` (12 участков полной
игры), `demo` (200 демонстрационных полей), `shortIds` (6 случаев короткой игры).
Все снимки — **настоящие научные наблюдения** обзора ZTF Public Survey
(получение данных через IRSA): у каждого участка три датированных экспозиции
(UTC-дата, фильтр, выдержка, ссылка на исходный FITS) и координаты центра
кадра (ICRS/J2000). Происхождение зафиксировано в
`assets/observations/manifest.json` (URL, заголовки FITS, sha256 каждого
файла, решения курирования, благодарности обзора); `meta.dataset.manifest_sha256`
привязывает data.js к конкретной версии манифеста.

Оценка детектора (score, признаки, z) рассчитана **заранее** по 300 реальным
обучающим участкам квадранта q4 (без меток «нормы»; правило разделения и
контрольная сумма массива — в `meta.training`) по формуле
`score = max_i (f_i − median_i) / (p99_i − median_i)` — см. `meta.score_formula`;
пороги интерфейса «1» и «3» (`meta.thresholds`) — те же единицы. Растяжение
(asinh) и цвет меняют только PNG-превью, не оценки. В `photometry.note`
указан вид измерения: полный апертурный поток, PSF-фотометрия научного кадра
или фотометрия разностного изображения. Их нельзя считать одной величиной.

```bash
# регенерировать data.js напрямую (то же, что делает сборка; офлайн из кэша):
.venv/bin/python tools/generate_data.py --out app/data.js
# восстановить подготовленные массивы и зафиксированный FITS-кэш:
.venv/bin/python tools/prepare_demo.py
.venv/bin/python tools/prepare_curated.py
.venv/bin/python tools/import_observations.py download
.venv/bin/python tools/import_observations.py verify
```

Прогон на том же кэше даёт байт-в-байт тот же `data.js`. Фактический контроль
данных — `tools/check_artifacts.py --only-data` (подпроверка, полной попыткой
приёмки не считается): контракт координат/дат/источников, sha256 манифеста,
воспроизводимость генерации. Рецепты обработки поставляются в `sky-source.zip`
(`prepare_demo.py`, `prepare_curated.py`, `prepare_discoveries.py`,
`realdata.py`, `import_observations.py`, `generate_data.py`,
файлы происхождения и манифест наблюдений); сырой кэш FITS/NPZ в поставку
не входит — в `data.js` встроены только PNG-превью и метаданные.

## 4. Установка на Linux (без root)

```bash
unzip linux.zip
cd science-day
./install.sh                      # в $HOME/.local/share/science-day
./install.sh "/путь/с пробелами"  # произвольный путь
```

Установщик копирует игру, создаёт ярлык «Архив неизвестного» в
`$XDG_DATA_HOME/applications` (по умолчанию `~/.local/share/applications`) и
работает без sudo. Запуск без ярлыка: `xdg-open "$HOME/.local/share/science-day/index.html"`.

## 5. macOS (Apple Silicon) и другие системы

Распакуйте `apple-silicon.zip` и откройте `science-day/index.html` двойным
щелчком (Safari/Chrome/Firefox). Приложение платформенно-независимое: тот же
набор файлов, что и для Linux; `install.sh` на macOS только скопирует файлы и
подскажет, как открыть игру.

## 6. Телефон

Скопируйте `dist/phone.html` на телефон (мессенджер, кабель, флешка — что
угодно) и откройте в мобильном браузере. Файл полностью автономен: сеть не
нужна даже для картинок — все изображения, данные, звёздный атлас и истории
открытий встроены. В блоке «Источники, лицензии и данные атласа» оба файла —
исходники атласа (`sky-source.zip`) и полные тексты лицензий
(`LICENSES.txt`) — встроены прямо в страницу и скачиваются одним касанием
без сети.

## 7. Печать

Файлы из `dist/print/` печатаются на обычном A4 (цветной принтер желателен;
`cards.pdf` работает и в ч/б). PDF читаются с любого устройства, шрифты
встроены. Заранее, до смены площадки, распечатайте по одному экземпляру для
проверки различимости мелких деталей (слабый сигнал, след спутника).

- **ranking.pdf — предварительный рейтинг алгоритма** (офлайн-резерв экранного
  алгоритма, не соревнование групп): 12 участков в порядке убывания
  предварительной оценки, отметки прохождения порогов «1» и «3». Оценка —
  мера необычности (нормированное отклонение от типичных значений обучающей выборки),
  **не вероятность**: помеха тоже может набрать высокую оценку. Типы и
  объяснения на листе не раскрываются — его можно показывать группам.
- **cards.pdf — печатный резерв ручного поиска.** Первые страницы — карточки
  для групп: только кадры 1–2 с фактическими датами и фильтрами наблюдений,
  нейтральное название и пустые поля «наблюдение» и «версия»; вырежьте по
  пунктирным рамкам и раздайте. Последние страницы — только ведущему:
  вырезки с кадром 3 (доп-наблюдение за жетон; дата наблюдения подписана) и
  ответом (тип, оценка, независимый научный разбор, доказательство и ограничения);
  вырежьте и согните между снимком и ответом, скрыв ответ внутри. Снимок
  выдавайте по id карточки. До раскрытия ответа третий кадр выдаётся за жетон.
  После записанной версии можно бесплатно раскрыть ответ и третий кадр этого
  дела для обсуждения. Первую версию оставьте на бумаге рядом с уточнением.

## 8. Сценарий ведущего (коротко)

- **Полная смена**: 12 участков, 3 жетона доп-наблюдений. **Короткая**: 6
  участков (`GAME_DATA.shortIds`), 1 жетон. Один жетон = третий кадр одного участка;
  заявку можно подать после первого впечатления, пока ответ ещё не раскрыт.
- Навигация: звёздная карта или карточки — состояние общее, можно свободно
  переключаться. Версии: «Изменился сам объект», «Помеха на снимке»,
  «Заметных изменений нет», «Недостаточно данных».
- После сохранения версии «Что показали наблюдения?» открывает разбор только
  этого дела: третий кадр, объяснение, основания вывода, доступные измерения
  и оценку алгоритма. Заявка не тратится; все три кадра остаются доступны для
  сравнения. Версию можно уточнить, а вариант до первого раскрытия сохраняется.
- После последней версии «Посмотреть итоги» ведёт к «Научному совету».
  «Итоги и разбор» можно открыть досрочно: предупреждение показывает число
  участков без версии и просит подтвердить раскрытие всех ответов. Возврат к
  исследованию остаётся доступен, но знакомство с ответом уже отмечено.
- «Где мы на небе» рядом со снимками — рассказ о созвездии и масштабе поля.
  Его можно читать сразу: он не называет ответ. Известные звёзды и туманности,
  упомянутые как ориентиры, находятся за пределами маленького снимка.
- «ИИ в астрономии» — шесть историй: Кеплер-90i, SN 2023tyk, следы астероидов
  на снимках Хаббла, восстановление изображения M87*, поиск гравитационных линз
  и распознавание помех Gravity Spy. Выберите одну под вопрос группы, не
  пытайтесь прочитать все за сеанс. У каждой есть вопрос для обсуждения,
  ограничения и первоисточники. Для чтения и просмотра данных сеть не нужна;
  переход по внешним ссылкам требует интернета.
- Пороги «1» и «3» отбирают разные множества участков. Фактическую картину по
  текущему набору (кто между порогами, кто ниже обоих) печатает presenter.pdf —
  раздел «Пороги отбора». Строгий отбор не гарантирует открытие: обсудите цену
  пропуска и лишней проверки. В коротком наборе все оценки ниже минимального
  порога 0,5: алгоритм не отбирает ни одного поля. На s10 сравните этот пропуск
  с измеренным изменением яркости; не представляйте набор как доказательство
  общей эффективности ИИ.
- **Честные счётчики** (точные правила — в presenter.pdf) сопоставляют текущую версию
  группы с независимо обоснованным разбором (`expectedVerdict`), не с оценкой
  алгоритма. «Изменений найдено» — подтверждённые изменения с версией
  «Изменился сам объект»; «Изменений пропущено» — остальные подтверждённые
  изменения, включая неразобранные. «Помех распознано» — помехи, для которых
  группа выбрала соответствующую версию. «Проверок спокойных полей» — число
  заявок на участки без заметного изменения. Если объяснение случая не
  установлено, он не входит в счётчики доказанных изменений и помех.
  Счётчики учитывают уточнения после разбора и не складываются в общий балл.
  Рядом отдельно указано число участков без версии. Это обсуждение результатов,
  а не оценка первой попытки.
- Таймер идёт вверх; в панели ведущего есть пауза и сброс. Ключ ответов —
  только у ведущего: `presenter.pdf` (тип, оценка, даты наблюдений и пояснение
  каждого участка).
- Печатный резерв (раздел 7): карточки группам — только кадры 1–2; кадр 3 и
  ответ — у ведущего на вырезках (cards.pdf). Предварительный рейтинг
  алгоритма для обсуждения порогов — ranking.pdf.

Полная смена занимает 15–20 минут: вводная 2–3 минуты, исследование 8–12,
научный совет 3–5. Короткая — 5–7 минут: вводная 1, исследование 3–4,
совет 1–2. Демо-набор (200 реальных полей того же обзора) нужен ведущему для
отдельного обсуждения порогов; просматривать все 200 примеров с группой не
требуется.

## 9. Права и источники

- Снимки участков — настоящие научные наблюдения ZTF Public Survey (данные
  через IRSA); благодарности обзора воспроизводятся дословно в presenter.pdf,
  `LICENSES.txt` и `assets/observations/manifest.json`.
- Звёздная карта — NASA SVS «Deep Star Maps 2020» (Ernie Wright; каталоги
  Hipparcos-2, Tycho-2, Gaia DR2), звёзды — HYG v4.1 (CC BY-SA 4.0), линии и
  русские названия созвездий — Stellarium «western» (CC BY-SA 4.0 + Free Art
  License; переводы GPL-2.0+). Исходные файлы данных — `sky-source.zip`,
  полные тексты лицензий — `LICENSES.txt`.
- Кривая блеска Кеплера-90 — архив MAST (STScI), миссия NASA «Kepler»; кадры
  SN 2023tyk — настоящие продукты ZTF/IRSA (научные и разностные). График и
  кадры — производная обработка архивных измерений (не рисунки из публикаций).
- Реальные фотографии — ESA/Hubble (CC BY 4.0) и STScI (public domain);
  атрибуции воспроизводить дословно: см. `real/CREDITS.md` в поставке
  (исходник — `assets/real/CREDITS.md`).
- Шрифт печати — DejaVu Sans (свободная лицензия, встроен в PDF); шрифты
  интерфейса — системные.

## 10. Если что-то не работает

| Симптом | Решение |
|---|---|
| Игра не открывается двойным щелчком | Откройте `index.html` через браузер: `xdg-open путь/index.html` |
| `./install.sh`: «Permission denied» | Файл распакован без прав запуска — выполните `bash install.sh [путь]` |
| Ярлык не появился | Проверьте `~/.local/share/applications/science-day.desktop`; игру можно запускать напрямую из папки установки |
| На телефоне «файл слишком велик» | Передавайте `phone.html` кабелем/флешкой; открывать Chrome/Firefox/Safari последней версии |
| PDF не печатается | Откройте в любом PDF-ридере и отправьте на печать оттуда; проверьте, что файл докопировался целиком (размер из раздела 1) |
| Нужно восстановить данные | `.venv/bin/python tools/build_release.py --data-only` |
| Собралось не всё | Сборка печатает список отсутствующих файлов `app/` — завершите интеграцию и повторите; для ранней работы используйте `--data-only` |

Все пути в командах выше — относительные корня репозитория.
