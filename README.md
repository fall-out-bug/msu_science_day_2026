# msu_science_day_2026

«Охота за звёздными аномалиями: как ИИ видит то, что человек не успеет» —
офлайн-интерактив факультета ИИ на фестивале «Наука 0+», 10–11.10.2026.

## Структура
- `tools/generate_data.py` — генератор учебных данных и оценок
  (замороженные параметры — в docstring; курируемый сид контактного листа,
  инварианты печатает сам скрипт).
- `artifacts/` — сгенерированные данные (не в git, воспроизводится командой ниже).
- `assets/real/` — реальные астрономические примеры для панели ведущего,
  атрибуции и лицензии в `assets/real/CREDITS.md`.
- `app/` — игровой интерфейс (в работе).

## Воспроизведение данных
```bash
python3 tools/generate_data.py --out artifacts   # нужны numpy + Pillow
```
Итог: train 300 нормальных пар, контактный лист 12 участков (сид курируется
автоматически), демо-набор 200, `public.json` (кадры, признаки, оценки —
без ответов) и `key.json` (ключ объяснений — только для панели ведущего).

## Стек
Чистая статика: HTML+CSS+JS без сборки и сервера; запуск двойным кликом.
`fetch` на `file://` заблокирован — данные подключаются через `<script>` (`data.js`).
Расчёты без GPU. Поставка: папка на флешке + `install.sh` (копирование в `~/`,
ярлык, без root) + печатный резерв + автономный HTML для телефона.
