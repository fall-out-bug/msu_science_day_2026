# msu_science_day_2026

«Охота за звёздными аномалиями: как ИИ видит то, что человек не успеет» —
офлайн-интерактив факультета ИИ на фестивале «Наука 0+», 10–11.10.2026.

## Структура
- `tools/generate_data.py` — генератор учебных данных и оценок
  (замороженные параметры — в docstring; курируемый сид контактного листа,
  инварианты печатает сам скрипт).
- `artifacts/` — сгенерированные данные (не в git, воспроизводится командой ниже).
- `assets/real/` — реальные астрономические примеры для панели ведущего,
  атрибуции и лицензии в `assets/real/CREDITS.md`.
- `app/` — игровой интерфейс (в работе).

## Играбельный прототип
**Принято 01.10.2026:** пользователь признал прототип удачным; выбранное
направление — вариант A, игровой пульт обсерватории. Сохраняем сравнение
у снимков, необязательную подсказку алгоритма, пошаговую проверку,
реальные истории и переходы по звёздному небу.
Исходный прототип зафиксирован в ветке `prototype/observatory-accepted`;
это образец взаимодействия для основной реализации, не код для прямого
переноса в готовую игру. B/C остаются только вариантами для сравнения.

Откройте `app/prototype.html` в браузере; сборка и интернет для игры не нужны.
Варианты A/B/C переключаются нижней панелью, прямой выбор — `?variant=A`.
Это проба интерфейса на шести учебных сериях, не готовая фестивальная поставка.

Вариант A — пульт обсерватории: сравнение снимков, первое впечатление,
третий снимок и рабочая версия. Способы сравнения находятся над снимками;
подсказка алгоритма необязательна и не заменяет проверку.
Между участками показывается перелёт по условной карте, который можно
пропустить; при системной настройке уменьшенной анимации его нет.
Отдельные истории о Кеплер-90i и SN 2023tyk объясняют роль ИИ в реальных
исследованиях. Тексты доступны офлайн, внешние ссылки на источники — с сетью.
Игровые снимки синтетические; иллюстрации историй и карта — условные.

## Воспроизведение данных
```bash
python3 tools/generate_data.py --out artifacts   # нужны numpy + Pillow
```
Итог: train 300 нормальных пар, контактный лист 12 участков (сид курируется
автоматически), демо-набор 200, `public.json` (кадры, признаки, оценки —
без ответов) и `key.json` (ключ объяснений — только для панели ведущего).

## Стек
Чистая статика: HTML+CSS+JS без сборки и сервера; запуск двойным кликом.
`fetch` на `file://` заблокирован — данные подключаются через `<script>` (`data.js`).
Расчёты без GPU. Поставка: папка на флешке + `install.sh` (копирование в `~/`,
ярлык, без root) + печатный резерв + автономный HTML для телефона.
