## Сборка документов

Нужны Python Markdown, Playwright с Chromium и локальный bundle Mermaid. Из корня проекта, с имеющимися в этой рабочей сессии зависимостями:

```bash
.venv/bin/python tools/scenario-review/build-navigation.py
PYTHONPATH=/tmp/science-day-html-export .venv/bin/python tools/scenario-review/build-design.py --mermaid-bundle /tmp/mlsd-mermaid-tiny.js
.venv/bin/python tools/scenario-review/check.py
.venv/bin/python tools/scenario-review/check-navigation.py
.venv/bin/python tools/scenario-review/check-design.py
```

Пути `/tmp` принадлежат текущему окружению; на другом устройстве укажите установленные Markdown и Mermaid. В готовых страницах SVG встроены, внешних библиотек нет. Изображения навигации снимаются в 1920×1080; их можно открыть отдельно или в диалоге клавишами Escape и стрелками.

Выход — `designlab/comparison/docs/galaxy-game-design.html`, `first-shift-scenario.html`, ресурсы и `galaxy-design-offline.zip`. ZIP содержит текущие и исторические документы с локальными изображениями. Комментарии из серверной базы в ZIP не входят; через `file://` доступны только локальные заметки браузера.

## История и комментарии

Перед заменой сохранены `galaxy-game-design-before-nika.html` и `first-shift-scenario-before-nika.html` со всеми прежними идентификаторами. Новые фрагменты получают префиксы `n4d` и `n4s`; документы API по-прежнему `galaxy-gdd-v1` и `first-shift-v1`. Реестры `gdd-blocks.json` и `blocks.json` содержат объединение старых и новых привязок. База комментариев не переписывается, цитаты не переадресуются новому тексту.

Повторная сборка проверяет неизменность уже выпущенных идентификаторов. Для следующей смысловой редакции сохраняйте текущие страницы в историю и задавайте новые префиксы в сборщике. Исторический `build-design.py` в `history` — запись происхождения, не отдельная рабочая команда.

## Публикация и пределы проверки

Команды публикации находятся в `tools/scenario-review/README.md`: веб-образ расширяет сохранённую действующую игру, не пересобирая её из локальных изменений. Комментарии тестируются во временной SQLite, не на публичных данных.

Автоматические проверки покрывают два браузерных контекста комментариев, сохранность исторических цитат, навигацию, Full HD, ширины 1920/1280/900/390 и извлечённый ZIP без сети. Это проверка документа и макетов, не новой игры и не детского понимания. Ближайшая работа по игре — данные и воспроизводимый опыт исправления разметки; затем основной путь и пара CNN.
