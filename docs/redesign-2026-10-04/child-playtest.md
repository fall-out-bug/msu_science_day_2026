# Короткая проверка фестивальной смены

Проверяем уже опубликованную игру: http://192.168.50.12:8081/.
Без сети: распаковать `night-shift.zip` и открыть `index.html`.
Результатов детского прохождения пока нет. Эта инструкция — способ их получить.

**Вопрос:** сможет ли школьник 10–13 лет самостоятельно закончить смену,
понять пользу своего прибора и захотеть продолжить за отведённые 10–15 минут?
Пользователь уже подтвердил понятность третьего исследования и желание
продолжить; это полезное свидетельство, но время и детский опыт не измерены.

## Подготовка — около минуты

1. На отдельной вкладке/в другом профиле открыть игру, чтобы не стереть свою смену.
   У сохранённой смены при необходимости сначала скачать журнал.
2. Для проверки текущего варианта оставить **6 исследований** — выбранный
   по умолчанию режим. В следующей пробе можно отдельно проверить режим 3.
3. Дать ребёнку мышь или сенсорный экран. Ведущий говорит только:
   «Попробуй собрать прибор для исследования неба. Можно пользоваться подсказками».
4. Засечь время по нажатию «Принять смену». Обновления игры, перерывы и разговор
   о разработке не считать. Не сообщать игроку о необходимости торопиться.

## Во время игры

Наблюдать, не показывая нужную точку. Отмечать события в таблице ниже.
Встроенная подсказка — часть игры; помощь ведущего записывается отдельно.
Если игрок просит помощи, сначала попросить показать место, которое непонятно.
Если он хочет остановиться, записать эпизод и причину.

| Событие | Время от начала | Наблюдение |
|---|---|---|
| Первое осмысленное действие на снимках | | Сам / после помощи ведущего |
| Проверка движения по третьему снимку | | Понимает, что проверялось / неясно |
| Исправление примера прибора | | Сам нашёл отличие / понадобилось объяснение |
| Завершено третье исследование | | Проверил версии / нажимал без понимания |
| Показан финал смены | | Количество исследований; общее время без перерывов |
| Нажал продолжение или решил закончить | | Собственное решение игрока |

Дополнительно записать только конкретные затруднения: название эпизода,
кнопку или действие, ожидание игрока и результат на экране. Не заменять
наблюдение общей оценкой «всё понятно» или «скучно».

## После финала — три коротких вопроса

- «Покажи в журнале результат, которым ты доволен. Что здесь произошло?»
- «Что теперь делает прибор и как ты проверял его предложения?»
- «Хочешь открыть следующие исследования? Почему?»

Достаточно кратко записать ответы без имени ребёнка. Не объяснять правильный
ответ до записи: иначе мы измерим объяснение ведущего вместо игры.

## Что менять по результату

- Если 6 исследований помещаются в 10–15 минут, действия понятны и ребёнок
  выбирает продолжение, сохранять этот режим как основной.
- Если ребёнок понимает действия, но не успевает, проверить режим 3 на новом
  прохождении. Укоротить первую смену можно без удаления продолжения.
- Если застревает на одном действии, исправить его цель, управление или обратную
  связь. Не компенсировать непонятный интерфейс устными подсказками ведущего.
- Если всё понятно, но продолжать не хочется, выяснить, какой эпизод воспринимается
  повторением и какой результат хотелось получить. Быстрое прохождение само
  по себе не исправлять искусственными задержками.

Одна проба выявляет конкретные препятствия. Для вывода о фестивальном режиме
нужны несколько самостоятельных прохождений; длительность одного знакомого
с проектом взрослого не переносится автоматически на всех детей.

## Минимальный ответ для следующей правки

Достаточно прислать: **режим 3/6/9; время до финала; где понадобилась помощь;
что игрок сказал о своём приборе; захотел ли продолжить**. Записи прохождения
или персональные данные для этого не требуются.
