# Проверка цели по состоянию сборки 4 октября

Цель остаётся полной: готовая детская научная игра на согласованных механиках,
с интересом к изобретению приборов и ИИ, для Наука 0+, 10–13 лет. Рабочий билд
и проверенные расчёты не доказывают, что посетителю интересно и понятно.

Предыдущий шаг дал прогресс: исправленный третий эпизод опубликован, сохранение
старой смены восстановлено без потери двух исследований. Этот шаг добавил
видимый журнал доказательств и устранил неверное завершение поздних вопросов.

| Требование | Текущее свидетельство | Вывод |
|---|---|---|
| Запускаемый готовый билд | Контейнер 8081, автономный ZIP; SHA ресурсов и образа в `night-deployment.json` | Технически выполнено |
| Целая смена, 3–9 исследований | Полные пути 3/6/9, продолжение, финал, reload; `night-browser.json`, `night-offline.json` | Выполнено в проверенных путях |
| Работа со звёздным небом | Реальные пиксели/даты ZTF, выбранные точки, прогноз третьего положения, фотометрия; provenance и независимые числовые проверки | Выполнено |
| Изобретение полезного инструмента | Проверка вручную открывает автоматический поиск на независимом поле; wrong-tool проверки не дают ложного завершения | Выполнено технически; ощущение авторства требует игрока |
| ИИ шире LLM | Обучаемый отбор по признакам и размеченным примерам, геометрическая проверка и измерения; `learning-model.js`, Python-эталон и `night-learning.json` | Выполнено; преимуществ ML на всём небе не заявляем |
| Действие с видимым исходом | Снимки/координаты/измерения остаются в журнале, вновь открываются и экспортируются в самостоятельный HTML | Выполнено технически |
| Честная награда | Обычная звезда не завершает вопрос об усилении или одиночном сигнале; неверный способ поиска не закрывает движение; 100→82→101 сохраняется как неопределённость | Исправлено и проверено на настоящих данных |
| Научный рассказ | Ника ведёт смену; карточки о движении, сверхновой, переменности и проверках содержат первичные источники | Присутствует; вовлечение не измерено |
| Референсы, оценки и отзывы | `references.md`: четыре игры, первичные страницы и датированный срез отзывов, перенесённые приёмы | Выполнено; оценки чужих игр не доказывают качество нашей |
| Допустимый визуальный подход | По последнему решению пользователя нейтральный интерфейс, настоящие снимки и функциональная анимация, без декоративных SVG | Выполнено в согласованном текущем подходе |
| Фестивальная устойчивость | Локальные ресурсы, пауза/продолжение/новый игрок, клавиатура, reduced-motion, ширина390, экспорт без сети | Проверенные пути проходят |
| Понятность третьего эпизода | Последний человеческий отзыв выявил проблему. Новая версия прошла технические проверки, повторного человеческого отзыва пока нет | Не доказано |
| Интерес детей10–13 и ритм10–15мин | Возраст/ритм учтены как проектная цель; самостоятельного детского прохождения с временем нет | Не доказано |

Ссылки на проверки: `designlab/comparison/evidence/night-*`.
Технические проверки не заменяют последние две строки. Общая цель пока не
помечается завершённой. Следующее свидетельство — прохождение новой версии
человеком: понимает ли он вклад своего примера, хочет ли продолжить, где теряет
цель. Пользователю отправлен один вопрос про третье исследование с возможностью
отдельно отметить «понятно, но неинтересно». Новые механики без такого основания
не добавляются ради самого продолжения работы.
