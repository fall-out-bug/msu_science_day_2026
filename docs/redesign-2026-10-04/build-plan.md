# Ночная смена: критерии готового билда

Цель пользователя: законченная детская научная игра для Наука 0+, 10–13 лет,
в духе МГУ и факультета ИИ. Основа — согласованные действия с настоящими снимками,
изобретение инструмента, объяснимый результат, любовь к науке. Цель не заменяется
одним эпизодом или набором технических тестов.

## Принятые решения 4 октября

- Браузерная сборка с существующими научными моделями и локальными ресурсами.
  Переход на 3D-движок не решает текущую проблему: разорванные действия и последствия.
- Единое рабочее место с наблюдением, инструментами, журналом и итогом. Декоративные
  SVG персонажей/обсерватории не возвращаются. Оформление нейтральное; движения
  показывают сравнение кадров, измерение, отбор и сохранение результатов.
- Полный маршрут: ручное наблюдение → проверка → инструмент → примеры для модели
  → независимое поле → журнал и финал. Измерение света и противоречивые случаи
  расширяют маршрут. Начало объясняет конкретную задачу без лекции.
- Выбор 3/6/9 исследований доступен только при наличии реальных проверенных данных.
  Общие исходные экспозиции и повторные проверки помечаются честно.
- ML действительно пересчитывается из примеров ребёнка. Исправление влияет на
  отбор; игрок указывает несовпадающую точку ошибочного следа и может отменить пример. Геометрическое правило
  остаётся доступным: не ухудшаем его, чтобы оправдать ML.
- Нет жёсткого таймера и наказания за исследование. Помощь по запросу, понятное
  объяснение неудачи, обратимые решения. Утверждение «пока неясно» — полезный итог.
- Целевой фестивальный ритм 10–15 минут, продолжение и сохранение между открытиями.
  Автоматический walkthrough не измеряет время самостоятельной детской игры.

## Требования и свидетельства при завершении

| Требование | Что должно доказать готовность |
|---|---|
| Действие с понятной целью с начала | Скриншот/прохождение без справочника, короткая инструкция и доступное первое действие |
| Научные снимки и честные выводы | Хеши исходников, независимые измерения, отдельные тесты моделей, provenance |
| Сборка полезного инструмента | Результат ручной проверки меняет доступный инструмент; полный путь проверен |
| Реальное обучение | Изменение примеров меняет расчёт на другом поле; undo возвращает прежний отбор |
| Содержательная кампания | 3/6/9 доступных различных задач с сохранением и финалом, без фиктивных повторов |
| Постоянная обратная связь | Выбор/ошибка/проверка/награда визуально читаются, результат остаётся в журнале |
| Детский русский язык | Редакторский обзор всех игровых реплик, минимум терминов в обязательном пути |
| Научная история и ИИ | Первичные источники, доступные после собственного действия, отсутствие выдуманного открытия |
| Готовый локальный билд | Контейнер8081, ZIP с локальными ресурсами, проверка без сети, инструкция запуска |
| Доступность и устойчивость | Клик/клавиатура/касание, reduced-motion, звук отключается, pause/resume/reset, мобильный viewport |
| Интерес/10–15 минут | Человеческое прохождение; до него остаётся явно непроверенным, не выдаётся за факт |

## Референсы

[Исследование оценок и отзывов](references.md), [аудит текущей игры](build-audit.md).
Наблюдение → проверенный след → установленный инструмент → объяснимый результат
