## Учебная часть и замечания

Игрок сам размечает шесть примеров с настоящими снимками. Модель ближайших
примеров обучается только на этих метках и признаках, затем проверяется
на девяти связях с другого участка. Контроль не входит в обучение.
С правильными метками результат — 7/9, две ложные тревоги. Ошибочная метка
меняет отбор; исправление позволяет сравнить результаты. Все числа вычисляются
из данных. После просмотра контроля и подбора меток это уже повторный эксперимент,
а не слепая оценка качества. Учебная модель не заявляет точности на всём небе.

## Исправление загрузки после замены прототипа

В чистом браузере ошибка не воспроизводилась. Старый образ отдавал `/data.js`,
который создаёт `GAME_DATA`; новый использует тот же путь, но ожидает
`COMPARISON_DATA`. Проверка с настоящим HTTP-кэшем прежнего API воспроизвела
все четыре сообщения пользователя: undefined `cases`, два отсутствующих
`COMPARISON_DATA`, отсутствующий `NightModel`.

Сборщик теперь добавляет к каждому скрипту и стилю параметр `v` с хешем содержимого.
Кэш прежнего URL больше не подменяет зависимость; порядок скриптов сохранён.
Тот же тест проходит без ошибок и открывает комнату. Это подтверждает механизм
сбоя; кэш конкретного пользовательского браузера не извлекался.
`no-store` сохранён, но сам по себе не очищает ранее закэшированные ответы.

При повторной проверке также исправлено перекрытие кнопки прибора длинной репликой
в окне 900×600. Проверка рабочих мест расширена на все пять кнопок и пять размеров.
